Recovery Centre

Open a case to organise the facts and transaction references connected to a suspected loss, scam or unauthorised transfer. Sign in first.

Start an incident record

Never enter a seed phrase, private key, password, recovery code or wallet connection link. Only submit public wallet addresses, transaction hashes and incident facts.

What happens next

Evidence first. No promises.

01Keep screenshots, emails, exchange notices and original transaction IDs.
02Check the transaction on the official explorer for the selected network.
03Report promptly to the exchange, wallet provider and relevant authorities.

A transaction trace is not the same as asset recovery. ChainRestore provides educational and documentation support, not a guarantee of retrieving funds.
