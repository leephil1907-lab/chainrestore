Agent Portal

For approved team members supporting education, case documentation and customer communication.

Agent onboarding

01Receive an official invitation from the platform administrator.
02Sign in using your own email and never share one-time codes or account credentials.
03Complete security and customer-care training before handling requests.
04Use approved communication channels and document every customer interaction.
Request agent information

Agent conduct standards

Agents must never request private keys, seed phrases, passwords, one-time codes, remote-device access or advance payments in exchange for a promised recovery. Never claim guaranteed recovery or impersonate an exchange, wallet provider, regulator or law-enforcement agency.

Agent accounts are provisioned by an administrator. Public sign-up does not grant agent privileges. This page provides onboarding guidance; it does not expose customer cases or private agent credentials.
